# Проверка переноса

`npm test` выполняет 26 тестов контрактов и реальной симуляции, включая:

- неизменяемые снимки состояния, изолированные обработчики и подписки;
- старые сохранения, pending-event DTO и атомарный отказ загрузки;
- повторение одинаковых команд с одним seed и продолжение после сохранения;
- жильё, обмен запчастями, повторные предложения соседей и ограниченный запас спасаемых;
- 84 рассчитанных месяца для каждой исходной угрозы на подготовленной базе, с реальными событиями и конечными показателями.

Тестовые базы полных кампаний имеют развитую инфраструктуру и запасы. Это проверка расчёта всех месяцев и взаимодействия систем, а не доказательство проходимости любой стратегии или нового баланса.

`npm run build` выполняет проверку типов и создаёт серверную и самостоятельную сборки.

Браузерная проверка выполняется отдельно в Chromium: запуск, постройка, вкладки, сохранения, торговля, эвакуация, окончание кампании, аудио, панорамы, мобильная ширина и разрез. Проверки среды не подменяют прослушивание всех встроенных реплик человеком.

Скрипт `tests/browser_smoke.py` воспроизводит 25 браузерных проверок. Он требует Python, пакет Playwright и Chromium, отдельно от npm-зависимостей игры. При запущенном `npm run dev`:

```sh
python tests/browser_smoke.py
```

Другой адрес можно задать через `PREDEL_TEST_URL`, путь к Chromium — через `CHROMIUM_PATH`. Отчёт и снимки пишутся в игнорируемый каталог `test-results/`.
