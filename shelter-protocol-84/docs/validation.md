# Проверка переноса

`npm test` выполняет 26 тестов контрактов и реальной симуляции, включая:

- неизменяемые снимки состояния, изолированные обработчики и подписки;
- старые сохранения, pending-event DTO и атомарный отказ загрузки;
- повторение одинаковых команд с одним seed и продолжение после сохранения;
- жильё, обмен запчастями, повторные предложения соседей и ограниченный запас спасаемых;
- 84 рассчитанных месяца для каждой исходной угрозы на подготовленной базе, с реальными событиями и конечными показателями.

Тестовые базы полных кампаний имеют развитую инфраструктуру и запасы. Это проверка расчёта всех месяцев и взаимодействия систем, а не доказательство проходимости любой стратегии или нового баланса.

`npm run build` выполняет проверку типов и создаёт серверную и самостоятельную сборки.

Браузерная проверка выполняется отдельно в Chromium: запуск, постройка, вкладки, сохранения, торговля, эвакуация, окончание кампании, аудио, панорамы, мобильная ширина и разрез. Проверки среды не подменяют прослушивание всех встроенных реплик человеком.

Скрипт `tests/browser_smoke.py` воспроизводит 27 браузерных проверок. Он требует Python, пакет Playwright и Chromium, отдельно от npm-зависимостей игры. При запущенном `npm run dev`:

```sh
python tests/browser_smoke.py
```

Другой адрес можно задать через `PREDEL_TEST_URL`, путь к Chromium — через `CHROMIUM_PATH`. Отчёт и снимки пишутся в игнорируемый каталог `test-results/`.

V18 дополнительно проверяет неизменность состояния при работе камеры, выбор комнаты, клавиатурное открытие и Escape.


## Интерфейс V19

Дополнительно выполнены проверки Chromium:

- `tests/window_layout.py` — 78 проверок: 11 панелей на 1440×900, 1024×600, 390×844, 320×568 и 844×390; длинные брифинги, звук, журнал, итоговый отчёт. Проверяются достижимость конца текста, доступность закрытия, отсутствие обрезания ширины и правильное открытие брифинга поверх терминала.
- `tests/atmosphere_browser.py` — 37 проверок: два вида на главном экране; четыре сценария × четыре этапа; шесть типов площадок; размеры Canvas; раскрытие и возврат панорамы; анимация, уменьшение движения и неизменность симуляции при работе камеры. Различия картинок этапов дополнительно проверены при фиксированном времени анимации.
- `tests/standalone_smoke.py` — 11 проверок собранного `dist/Predel.html` без доступа к сети: запуск, инспектор комнат, обменные предложения, эвакуация, брифинг и возврат панорамы на четырёх размерах экрана. Внешних запросов и ошибок JavaScript не обнаружено.

```sh
python tests/window_layout.py
python tests/atmosphere_browser.py
npm run build
python tests/standalone_smoke.py
```

Первые два скрипта используют запущенный Vite и те же переменные адреса и Chromium, что и основной браузерный тест. Автономная проверка загружает готовый HTML в браузер через `set_content` с отключённой сетью; политика этой тестовой среды запрещает навигацию по `file://`. Скриншоты интерфейса получены на тестовых сохранениях с подготовленными ресурсами и модулями.
